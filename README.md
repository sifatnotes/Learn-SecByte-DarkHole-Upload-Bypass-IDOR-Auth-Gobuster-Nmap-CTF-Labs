## Learning Path

A practical progression through this collection is:

1. **Start with Nmap** — identify accessible services and establish an initial attack-surface map.
2. **Practice web reconnaissance** — investigate the DarkHole web environment and identify application components.
3. **Use Gobuster concepts** — discover hidden directories and resources.
4. **Study authentication flows** — examine registration, login, account recovery, and session behavior.
5. **Explore IDOR and authorization** — understand how improperly protected resources can expose data or functionality.
6. **Study file uploads** — analyze how applications process uploaded files.
7. **Investigate upload filters** — understand validation and bypass concepts in a controlled environment.
8. **Connect the findings** — use enumeration and vulnerability analysis to understand complete CTF attack paths.

## How to Use the Labs

1. Select a challenge from the direct-link index.
2. Read the objective and confirm the authorized scope.
3. Begin with reconnaissance rather than immediately attempting exploitation.
4. Enumerate services, directories, endpoints, and application functionality.
5. Analyze authentication and authorization behavior.
6. Inspect upload validation when working with file-upload challenges.
7. Document each discovery and its security impact.
8. Test techniques only against the provided lab environment.
9. Review the underlying vulnerability and appropriate defensive controls after completion.
